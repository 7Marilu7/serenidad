#### Serenidad:

Aplicación móvil de bienestar emocional que permite registrar el estado de ánimo, realizar ejercicios de respiración, acceder a meditaciones guiadas y consultar el progreso personal.

Proyecto académico desarrollado como parte de la formación en desarrollo de aplicaciones móviles.

### Tecnologías
- Kotlin y Jetpack Compose
- Android Studio
- Arquitectura MVVM
- Firebase Authentication, Cloud Firestore y Storage
- Git y GitHub
